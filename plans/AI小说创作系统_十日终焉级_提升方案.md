# AI小说创作系统 →《十日终焉》级别 系统性提升方案

## 一、当前系统架构评估

### 优势（已具备）
- 19步完整创作流程（灵感→主题→大纲→世界观→人物→关系→弧线→势力→线索→简介→细纲→正文→审校→修正→合稿→回译→审查→质检→发布）
- 四层质量审查 + 五层世界观审查 + AI痕迹检测体系
- SQLite + ChromaDB 向量检索持久化
- 10项跨模块交叉验证 + 联动更新追踪

### 核心缺陷
**系统只有「流程编排」和「事后审查」两个能力维度，缺少第三个也是最关键的维度——「创作引导」**。

具体表现为：
1. `agent_prompt_hints` 只有关键词级提示，无系统性规则资产
2. 没有独立的推理/悬念设计引导模块
3. 参考小说目录未向量化利用
4. AI痕迹清除仅事后修补，无事前预防机制

## 二、四大结构性差距

### 差距1：缺乏专业级Prompt工程资产库

**当前：**
```yaml
agent_prompt_hints:
  - "逐场景独立生成，每个场景在自己的约束内运行"
  - "段落组实时跟踪字数"
  - "生成后执行四层审查和 AI 痕迹清除"
```

**目标：** 为每个创作步骤创建结构化规则文件，从「提示」升级为「规则集」。

### 差距2：缺乏推理/悬念设计的创作引导

《十日终焉》的核心竞争力在于精妙的逻辑推理设计。需增加：
1. **逻辑链强制检测** — 每个推理必须有完整证据链
2. **读者信息对等设计** — 反转需同时满足意外性和必然性
3. **谜题难度梯度设计** — 从易到难分级

### 差距3：缺乏高质量参考文本的向量化知识库

参考小说目录需：
- 按场景/对话/推理/情绪节点进行结构化标注
- 存入 ChromaDB 作为写作风格参照向量
- 在正文生成时自动拉取相似场景参考

### 差距4：AI痕迹消除缺乏事前预防

当前检测阈值过宽松（0.6-0.8），需：
1. 事前：在Prompt层面内置防AI痕迹规则
2. 事中：通过few-shot样例引导风格
3. 事后：严格化检测阈值

## 四、四层提升路径

### 第1层：Prompt工程资产化（短期·2-4周）

为全部19个步骤创建独立Prompt规则文件。

**实施步骤：**
1. 在项目根目录创建 `prompts/` 文件夹
2. 为每个创作步骤编写规则文件（已完成3个核心文件）
3. 改造 `step_protocols.yaml` 引用外部规则文件
4. 在相应模块中增加规则文件加载机制

**预计效果：** 产出质量提升50%，减少AI套路化表达

**预计效果：** 具备《十日终焉》级别逻辑推理链条输出能力

### 第3层：参考文本知识库（中期·1-2月）

**实施步骤：**
1. 对参考小说按维度进行结构化标注
2. 存入ChromaDB向量数据库
3. 在正文生成时自动拉取参考片段作为风格锚点

**标注维度：**
- 场景类型（对话/推理/战斗/情感/悬疑）
- 节奏曲线（每章冲突强度）
- 情感起伏（每500字主导情绪）
- 推理模式（线索→推导→排除→结论）
- 对话模式（角色语调、信息交换量）

**预计效果：** 文风从「AI通用风」转向「目标参考作品风格」

### 第4层：写作风格引擎（长期·3-6月）

**核心能力：**
1. **风格指纹提取：**
   - 句式分布指纹（短/中/长句比例曲线）
   - 过渡词使用指纹
   - 对话占比指纹
   - 情感表达指纹
   - 节奏指纹

2. **风格切换机制：**
```yaml
style_profiles:
  shiri_zhongyan:  # 十日终焉风格
    short_sentence_ratio: 0.35
    medium_sentence_ratio: 0.50
    long_sentence_ratio: 0.15

    dialogue_ratio: 0.45
    emotion_showing_ratio: 0.85
```
