# 新建小说创作流程 — 零脚本执行计划

> **⚠️ 核心规则：禁止创建任何临时 `.py` 脚本**
>
> 所有步骤必须通过 `StepExecutor.execute(step_num, content)` 执行。
> 禁止创建 `_step*.py`、`_check*.py`、`_fix*.py`、`_verify*.py` 等临时脚本。
> 禁止直接操作数据库或手动写入 system_data JSON。

## 一、架构概览

### 执行入口

```python
from src.core.workflow.step_executor import StepExecutor

# 初始化执行器
executor = StepExecutor(novel_id, db_session, chroma_client)

# 执行单步（禁止创建脚本）

# result.success        → bool
# result.summary        → str
# result.module_data    → dict（模块返回的数据）
# result.sync_status    → str（同步结果）
# result.errors         → list[str]
```

## 二、各步骤执行规范

### 通用规则

1. **生成 content**：根据步骤的期望格式生成结构化 JSON
2. **调用 execute**：`executor.execute(step_num, content)`
3. **展示结果**：向用户展示 `result.summary` 和 output 文件内容
4. **等待确认**：用户确认后再进入下一步
5. **修改处理**：用户要求修改时，更新 content 重新 execute

## 五、常见问题

### Q: 依赖步骤未完成怎么办？
`StepExecutor.execute()` 会自动检查依赖，失败时返回错误信息：
```
"依赖步骤 N「XXX」尚未完成（当前进度: M）。请先完成前置步骤再继续。"
```

### Q: 用户要修改上一步数据怎么办？
生成修改后的 `content`，重新调用 `executor.execute(step_num, content)` 即可。
模块的 `INSERT OR REPLACE` 会覆盖旧数据，SyncEngine 会自动同步到 output。

### Q: 如何查看当前步骤状态？

```python
from src.storage.database.engine import get_session
from sqlalchemy import text

with get_session() as s:
    rows = s.execute(
        text("SELECT step_number, step_name, status FROM step_status WHERE novel_id=:nid ORDER BY step_number"),
        {"nid": NOVEL_ID}
    ).fetchall()
    for r in rows:
        print(f"步骤{r.step_number}: {r.step_name} => {r.status}")
```
