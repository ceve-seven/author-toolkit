# 人物-势力关联规则集

## 1. 核心原则

### 1.1 每个角色必须与至少一个势力关联
- 主角必须明确归属某个势力
- 配角可以"无势力"（自由人/中立），但需标注
- 同一角色可同时隶属多个势力（双重身份/卧底/联盟关系）

### 1.2 角色身份与势力性质必须一致
- 军人类角色不能加入和平主义势力
- 学者类角色不能加入反智势力
- 贵族类角色通常不会加入平民革命组织（除非有特殊动机）

### 1.3 角色关系与势力关系必须兼容
- 两个敌对势力的成员之间不能是"亲密"/"恋人"关系（除非是卧底/禁忌之恋）
- 两个联盟势力的成员之间不应有"血海深仇"关系
- "师徒"关系通常只在同一势力或友好势力间成立

## 2. 验证规则

### 2.1 势力敌对检查
如果一个角色同时隶属多个势力，这些势力不能互为敌对关系。
- 若势力A与势力B为"敌对/战争/竞争"关系
- 角色X不能同时是A和B的正式成员
- 例外：双面间谍、被迫效忠（需在notes中标注）

### 2.2 角色-势力忠诚度检查
- "核心成员"的 loyalty >= 0.8
- "正式成员"的 loyalty >= 0.5
- "外围成员"的 loyalty >= 0.2
- "无关联"的 loyalty = 0.0
- 若loyalty低于对应阈值，记录一致性警告

### 2.3 跨势力角色关系检查
若两个角色分属不同势力，他们的个人关系不能与势力关系矛盾：

| 势力关系 | 可兼容的角色关系 | 不兼容的角色关系 |
|---------|----------------|----------------|
| 联盟/同盟 | 友好、合作、信任 | 敌对、仇敌、竞争 |
| 敌对/战争 | 敌对、仇敌 | 亲密、恋人、信任 |
| 中立 | 任何关系均可 | — |

### 2.4 势力内部层级一致性
- 高rank的成员不能对势力忠诚度过低
- 领导者/首领角色 weight 必须 >= 0.7
- 普通成员 weight 无限制

## 3. 输出字段说明

```
char_faction_links[]:
  - char_id: 角色ID
  - faction_id: 势力ID
  - membership_type: 成员类型（核心成员/正式成员/外围成员/无关联/卧底）
  - join_chapter: 加入章节（0表示开始前已加入）
  - leave_chapter: 离开章节（0表示未离开）
  - role_in_faction: 在势力中的具体职位
  - loyalty: 忠诚度 (0.0-1.0)
  - notes: 备注说明
```
