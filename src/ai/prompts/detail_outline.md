# 章节细纲生成规则集

## 0. 数据引用与交叉验证规则（强制）

在生成每章细纲前，**必须逐一核对以下所有输入数据**，确保生成的场景设定与已有数据完全一致。任何不一致即判定为逻辑漏洞，必须修正后再继续。

### 0.1 必须引用的数据源
生成每个场景时，必须从以下数据源中提取约束条件：

1. **角色数据（characters）**：
   - 角色名称、角色身份（主角/配角）、职业/社会地位
   - 角色能力范围（不能使用未设定的技能）
   - 角色知识边界（不能知道不该知道的信息）
   - 角色当前状态（生死/受伤/位置）
   - 操作方式：每引用一个角色，先查角色数据库确认其身份和能力边界

2. **物品数据（items）**：
   - 物品名称、功能描述、限制条件
   - 物品当前持有者和状态
   - 操作方式：场景中使用任何物品前，先验证该物品是否具备所需功能

3. **世界观数据（world_building）**：
   - 世界规则（物理规律/超自然规则）
   - 各维度的设定细节
   - 操作方式：场景设定必须与世界规则一致（如科幻世界不能出现魔法）

4. **伏笔数据（foreshadows）**：
   - 已埋设但未回收的伏笔
   - 计划回收章节
   - 操作方式：每章至少1个维持操作，每10章至少1个回收操作

5. **分卷配置（volumes）**：
   - 当前分卷的章节范围
   - 叙事重力方向
   - 操作方式：场景必须在该分卷的叙事框架内

### 0.2 生成前验证清单
每生成一个场景，必须依次回答以下问题：
- [ ] 该场景的 POV 角色是否在角色数据库中存在？角色是否还活着？
- [ ] 场景中涉及的物品是否在物品库中登记？功能是否匹配？
- [ ] 场景中的角色行为是否在其知识边界和能力范围内？
- [ ] 场景的时间设定是否与前后章节一致？
- [ ] 场景设定是否违背世界观规则？
- [ ] 该场景的信息释放量是否超标？（核心信息≤1条/章，次要信息≤3条/章）
- [ ] 当前场景的伏笔操作类型是否有效？（埋设/维持/回收）

以上任意一项答案为"否"，则必须修改场景设计。

### 0.3 常识性底线
以下常识性错误在任何情况下都禁止出现（无论世界观如何设定）：
- 黑暗环境中不能阅读/看清颜色
- 水下不能大声说话/深呼吸
- 真空/太空听不到声音
- 已死亡的角色不能在后续章节中再次登场（回忆/闪回除外）
- 角色的伤势不会在没有医疗的情况下自动恢复
- 相邻章节的时间线不能倒退

## 1. 场景分割规则

每章的场景分割遵循以下标准：
1. **场景切换条件**（满足任一即分景）：
   - 时间跳跃（> 30分钟）
   - 空间移动（更换地点）
   - POV切换（更换视角角色）
   - 情绪基调改变（紧张→松弛/悬疑→动作）
2. **最小场景字数**：500字（太短则失去场景感）
3. **最大场景字数**：2500字（太长则读者疲劳）

## 2. 节奏梯度规则

连续5章内，冲突强度配置必须满足：
- 高强度（≥8/10）：不超过2章
- 中强度（4-7/10）：占2-3章
- 低强度（≤3/10）：至少1章（冷却和铺垫）

## 3. 伏笔分布规则

每章伏笔引用遵循：
- 埋设：新伏笔的引入
- 维持：已埋设伏笔的强化/暗示
- 回收：伏笔的揭晓
- 每章至少要有1个"维持"操作（让已有伏笔保持活跃度）
- 每10章至少要有1个"回收"操作（给读者奖励感）

## 4. 信息释放节奏规则

每章的信息释放量控制：
- 核心信息（关于主线/世界观/主角身份）：每章不超过1条新核心信息
- 次要信息（关于配角/势力/历史）：每章不超过3条次要信息
- 连续2章无任何新信息 → 标记为信息饥饿区间

## 5. POV分配规则

多角色POV时：
- 主角POV占比：全文50-70%
- 单一配角POV：连续不超过2章
- POV切换必须在场景分割处，不得在场景中间跳跃
- 同一事件通过多个POV展示时，POV信息必须有差异化（不是简单重复）

## 6. 常识性约束规则（强制）

细纲生成时必须确保以下常识正确性，否则判定为不合格：

### 6.1 物理常识
- 黑暗/无光环境中角色不能"阅读""看清颜色""观察细节"
- 水下场景角色不能"大声说话""深呼吸""哭泣（眼泪与海水混合）"
- 真空/太空环境角色不能"听到声音""风吹过"
- 角色不能"看到"自己的后脑勺/背面/闭眼时的表情
- 隔着墙壁/门板不能清晰听到低声对话
- 高速移动中（奔跑/驾车）无法细致观察周围事物
- 从明亮环境突然进入黑暗，需要适应时间（30秒-3分钟）
- 从寒冷室外进入温暖室内，眼镜会起雾

### 6.2 生物常识
- 人类失血超过全身30%会休克，超过50%危及生命
- 溺水后缺氧超过4分钟会造成脑损伤
- 人在极度恐惧时可能失禁（应激反应），这不是"丢人"而是生理事实
- 剧烈运动后不能立即大量饮水
- 长时间不进食/不睡眠会严重影响认知能力
- 人在低温环境中（<10°C）会发抖、手指僵硬、说话不清

### 6.3 社会常识
- 正式场合的对话不用"哥们儿""老铁"等过于随意的称呼
- 上下级关系中，下级不会随意打断上级
- 陌生人间首次见面不会直奔最私密的话题
- 警方/军方行动有基本的流程和层级（不是一个人说了算）
- 医院急诊有分诊流程，不会因为主角来了就插队
- 新闻媒体发布重大消息需要核实流程，不是立刻全网推送

### 6.4 禁止的常识性错误
- 角色已死亡/退场后，在后续场景中无故再次出现
- 角色的伤势在无医疗处理的情况下自行恢复
- 同一时间角色出现在两个不同地点
- 历史/科技设定与时代背景明显不符（如古代出现现代物品）

## 7. 主角与POV切换规则（增强版）

### 7.1 主角连续性
- 主角必须出现在每卷至少50%的章节中（通过POV或实际出场）
- 连续配角POV章节数不得超过2章，否则读者会忘记谁是主角
- 主角"掉线"超过3章后必须让其他角色通过对话提及主角近况

### 7.2 POV信息差规则
- 配角POV不能揭示主角不应该知道的信息（破坏悬念）
- 配角POV揭示的信息必须是"读者需要知道但主角还不知道"的
- 禁止通过配角POV揭示"最终答案"或"终极真相"
- 如果必须在配角POV中给出关键信息，后续必须从主角视角重新验证

### 7.3 POV切换标记
- POV切换必须在场景分割处明确标记（通过场景分隔）
- 同一场景内禁止POV跳跃（从A的内心活动直接切到B的视角）
- 第一人称与第三人称不得混用

## 8. 配角身份一致性规则

### 8.1 知识边界约束
- 配角的认知范围必须与其身份/职业/经历一致：
  - 普通市民不可能知道军方机密
  - 基层警员不可能掌握全局部署
  - 新出场角色不可能知道主角的过往秘密
- 配角说出超出其知识边界的信息 → 判定为逻辑漏洞

### 8.2 称呼一致性
- 每个配角的称呼必须在全文中保持一致：
  - 不能一会儿"王局长"一会儿"老王"（除非关系变化贯穿剧情）
  - 首次出场必须明确全名/身份，后续可使用简称
  - 多个角色不能共用同一称呼（不能有两个"老王"）

### 8.3 立场与阵营约束
- 配角的立场/阵营不得无故改变：
  - 如需转变，必须安排至少2章的铺垫
  - 转变驱动力必须明确（利益/威胁/情感/认知变化）
  - 反复横跳（两次以上立场变化）需要更强的动机支撑

### 8.4 能力一致性
- 配角的技能/能力不能凭空出现：
  - 第1-5章未提及的技能，第15章突然使用 → 需要2章以上铺垫
  - 配角的战斗能力需要与设定一致（文职人员不能突然搏击高手）
  - 配角的性格特质决定了其行为模式（谨小慎微者不会突然莽撞）

## 9. 时间线一致性规则

### 9.1 时间流逝约束
- 单章内时间跨度不得超过24小时（除非明确标记时间跳跃）
- 时间跳跃必须标注：如"三天后""两周过去"等
- 多POV并行的章节，各POV时间线必须对齐

### 9.2 昼夜/天气一致性
- 同一场景内的昼夜状态必须一致：
  - 前一场幕"夕阳西下" → 下一场不能"烈日当空"
  - 如果跨越数小时，中间需要明确时间过渡
- 天气变化需要合理过渡（不能上一句晴天，下一句暴雨）
- 时间流逝速度与现实一致（不能在"紧急时刻"突然慢动作化）

### 9.3 事件顺序约束
- 因果顺序不能颠倒：
  - 必须先发生A事件，再看到A事件的后果
  - 角色不能做出基于"尚未发生事件"的决策
- 倒叙/插叙必须用明确的时间标记区分

### 9.4 场景衔接
- 相邻场景之间的时间间隔必须明确可推断
- 跨章节的同一条情节线，时间起点必须衔接
- 不可出现"上一章结尾是深夜紧急，下一章开头是悠闲的午后"

## 10. 物品功能一致性规则

### 10.1 物品功能约束
- 物品只能使用其已设定的功能：
  - 设定为"信号干扰器"的物品不能用于"破解密码"
  - 设定为"装饰品"的物品不能有隐藏功能（除非伏笔铺垫）
- 物品的功能扩展需要至少3章以上的伏笔铺垫

### 10.2 物品状态一致性
- 物品的状态必须跨场景/跨章节保持一致：
  - 已损坏的物品不能后续完好出现
  - 已消耗的物品不能再次使用
  - 已丢失/被夺的物品不能无故回到手中
- 每次物品状态变化必须在剧情中有交代

### 10.3 物品所有权
- 物品的所有权转移必须有明确剧情交代：
  - 不能"不经意"出现在不同角色手中
  - 借用/赠送/抢夺都需要明确标注
  - 关键物品的所有权转移必须由主角/对立角色双方知晓

### 10.4 物品使用限制
- 消耗品（子弹/药剂/能源）的使用次数必须被追踪：
  - 不能出现"无限子弹"或"前一天用完第二天又有"的情况
  - 特殊物品的使用间隔/冷却时间需要保持一致
  - 物品的使用后果（副作用/反噬）不能无理由消失
