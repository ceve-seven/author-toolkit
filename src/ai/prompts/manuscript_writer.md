# 正文初稿生成规则集

## 0. 数据引用与逻辑验证规则（强制）

生成每个场景的正文前，**必须逐一核对以下所有数据源**，确保正文内容与已有设定一致。任何不一致即为逻辑漏洞，必须修正后才能进入下一场景。

### 0.1 必须交叉引用的数据

1. **角色数据（characters）**
   - 核对每个出场角色的身份、职业、能力范围
   - 角色不能说超出其知识边界的话（普通市民不知军事机密）
   - 角色不能使用未设定的技能（文职人员不会突然搏击）
   - 死亡的不能在后续正文中再次出场（回忆/闪回除外）
   - 操作方式：每写一个角色出场，先对照角色数据确认其身份和能力

2. **物品数据（items）**
   - 物品只能使用其已设定的功能
   - 消耗品使用次数必须追踪（不能无限弹药）
   - 已损坏/丢失的物品不能无故完好出现
   - 操作方式：每使用一个物品，先查物品数据确认其功能和限制

3. **世界观数据（world_building）**
   - 物理规则必须与世界设定一致（科幻世界不能出现魔法）
   - 超自然规则必须在世界观中有明确设定
   - 操作方式：场景设定不能违背世界观规则

4. **伏笔数据（foreshadows）**
   - 每章至少1个伏笔维持操作
   - 伏笔回收必须与埋设内容一致
   - 操作方式：参照伏笔数据安排每章的伏笔操作

### 0.2 常识性底线检查

以下常识性错误在正文中**零容忍**，出现即判定为不合格：

- **视觉矛盾**：黑暗/无光环境中角色不能阅读/看清颜色/观察细微特征
- **听觉矛盾**：水下不能大声说话/喊叫（除非通过通讯设备）
- **物理矛盾**：真空/太空听不到声音、没有风
- **生死矛盾**：已死亡的角色只能在回忆/闪回中出现
- **伤势矛盾**：重伤角色在没有医疗处理的情况下不能自行恢复
- **位置矛盾**：同一时间角色不能出现在两个不同地点
- **时间矛盾**：前一章结尾是深夜，下一章开头如果是白天必须标注时间跳跃

### 0.3 每段正文生成前检查清单

每写一个场景，完成以下检查：
- [ ] 场景中每个出场角色的身份和能力是否与角色数据一致？
- [ ] 场景中使用的每个物品是否在物品库中登记？功能是否匹配？
- [ ] 场景设定是否违反物理常识（黑暗/水下/真空）？
- [ ] 该场景的时间段是否与前后场景衔接？
- [ ] 该场景是否包含已死亡的角色的再次出场？
- [ ] 该场景中所有角色的对话是否符合其知识边界？
- [ ] 该场景的信息释放量是否合理？

## 1. 开篇钩子法则（第1-3章强制）

每条开篇必须完成以下三层：
1. **悬疑层**：在第1章结束前提出一个让读者无法停止追问的根本性问题（如：为什么全员「说谎者」？为什么房间空气不够？）
2. **威胁层**：在第2章结束前引入不可逆的致命威胁（如：山羊头杀人、鱼叉即将发射）
3. **超越层**：在第3章结束时暗示存在远超当前认知的更大世界观（如：全员已死、游戏不止一个）

禁止行为：
- 前三章出现大段世界观说明
- 主角通过"传承记忆"或"系统提示"获得信息
- 前三章无实质性死亡/毁灭威胁

## 2. 角色行为一致性规则

每段角色行动前，必须检查：
1. **动机链完整性**：角色做某事的理由是否在之前1-3章内有铺垫
2. **知识边界**：角色是否在做"他不可能知道的事"或"忽略他应该知道的信息"
3. **性格一致性**：角色的选择是否符合其已建立的人格特质（齐夏会主动隐藏信息但不会主动杀人）

## 3. 对话写作规则

每段对话至少满足以下2项：
- 推动情节（揭露信息/改变关系/制造转折）
- 塑造性格（语气、用词、停顿、打断方式体现角色差异）
- 制造紧张（潜台词冲突/权力博弈/信息差）

禁止：
- 对话成为纯粹的信息搬运工具
- 两个角色用相同的语气和句式说话
- 每段对白超过5轮无信息增量

## 4. 推理场景规则

当角色进行推理时，必须满足：
1. **线索前置**：推理所使用的所有证据必须在3章内有明确铺垫
2. **逻辑链条可视化**：推理过程必须包含"前提A→推导B→排除C→结论D"的完整链条
3. **信息差设计**：读者应当能跟上推理但略慢半拍，不能出现"读者完全无法理解"或"读者早就猜到"的局面

## 5. 节奏控制规则

每800字必须出现以下至少1项：
- 新信息揭露
- 情绪变化（紧张→松弛/恐惧→愤怒/悲伤→希望）
- 悬念强化（引入新问题/深化已有危机）
- 场景/视角切换

连续1000字无以上任一项 → 标记为节奏塌陷，需重写该段落

## 6. 句式多样性规则

每300字范围内：
- 同一种句式开头（如"他""她""这"）不超过2次
- 至少包含1句短句（≤8字）和1句中长句（≥25字）
- 过渡词（然后、接着、于是、但是、然而）密度控制在每500字≤2次

## 7. 情感层次规则

每章必须包含至少1处以下情感的间接表达（非直接告知）：
- 通过身体反应表现恐惧（发抖/出汗/瞳孔变化）
- 通过动作表现愤怒（捏拳/踢东西/笔尖戳破纸）
- 通过沉默表现悲伤（停顿/话说到一半中断）
- 通过细微动作表现隐瞒（视线游移/摸鼻子/话题转移）

禁止直接告知情感：禁止出现"他感到恐惧""她非常愤怒""心中充满了悲伤"

## 8. AI痕迹检测与清除规则（强制）

每章生成后必须执行以下全部AI痕迹检测。有任何一项未通过则必须修改后再进入下一章。

### 8.1 "不是A，是B"否定对比句检测
检测目标：连续使用"不是……是……"的否定对比句式，是AI最明显的语言模式。

判定规则：
- 同200字内出现超过1处"不是A，是B"结构 → 判定为AI痕迹
- 同章内"不是"总出现次数超过10次 → 判定为AI痕迹
- 带引号的对比（如"不是'碎了'，是'消失了'"）→ 判定为强AI痕迹

修复方法：
- 把对比句改成直接陈述："规则是物理法则" 而非 "不是警告，不是威胁，是物理法则"
- 用破折号代替分割句："手碎了——不是掉了，是消失了" 
- 用具体描写代替否定："断腕处光秃秃的" 而非 "没有碎裂也没有愈合"

### 8.2 排比否定堆叠检测
检测目标：连续3+句以"不是"开头的排比，属于AI特征句型。

判定规则：
- 连续2句以上以"不是"开头 → 判定为AI痕迹
- 同一行内连续2次使用"不是" → 判定为AI痕迹

修复方法：
- 去掉排比结构，只保留一句肯定陈述
- 将否定句改为肯定句叙述

### 8.3 "像……一样"比喻堆叠检测
检测目标：过度使用"像/仿佛/如同……一样/一般"的比喻结构。

判定规则：
- 同500字内连续出现超过2处"像/仿佛"比喻 → 判定为AI痕迹
- 全章"像"比喻超过5处 → 需精简

禁止模式：
- "就像他的手从来没有存在过一样" → 改为"光秃秃的"
- "像活着一样" → 改为"在动"
- 比喻应当精简到极致，每章不超过3处

### 8.4 同句式开头率检测
检测目标：全章以同种主语开头的句子比例。

判定规则：
- 以"他/她/它/这/那"开头的句子占全章比例 > 15% → 判定为AI痕迹

修复方法：
- 用时间状语开头："三分钟后……"
- 用地点状语开头："电梯门边……"
- 用动作结果开头："手碎了。"
- 用短句开头（≤4字）："七条规则。""不想知道。""没用。"
- 用对话继续，省去"他说"引导
- 每300字范围内，同一种句式开头不超过2次

### 8.5 过渡词密度检测
检测目标：过度使用连接词。

判定规则：
- 每500字过渡词（然后、接着、于是、但是、然而、所以、因此）超过2次 → 判定为AI痕迹

修复方法：
- 直接连续叙述，去掉"但要但所以"
- 用破折号或冒号代替"但是""然而"
- 用短句代替逻辑连接词

### 8.6 结构性过渡词禁止
检测目标：AI 在小说正文中使用论述式结构标记。

禁止出现以下词汇（小说正文中任何位置）：
- 首先、其次、再次、最后、总之、总而言之、总的来说
- 值得注意的是、需要指出的是、不可否认、众所周知
- 换言之、换句话说、也就是说、毋庸置疑
- 综上所述、由此可见、不难看出
- 一方面……另一方面……
- 第一、第二、第三（作为论述标记）

修复方法：
- 直接删除这些词，靠叙事推进，不做论述
- "值得注意的是，他的眼神变了" → "他的眼神变了"
- "首先，他感到恐惧，其次……" → 直接写恐惧的具体表现

### 8.7 模糊化表达禁止
检测目标：AI 过度使用模糊化词汇削弱叙事力量。

每千字模糊词（似乎、或许、不禁、某种、仿佛等）超过3次 → 判定为AI痕迹

禁止高频使用以下词汇：
- 似乎、或许、也许、大概、可能（→ 直接用确定性叙述）
- 不禁、不由得、忍不住（→ 直接写动作，不要"忍不住"修饰）
- 某种、某种程度、某种意义上（→ 给出具体定义）
- 仿佛（→ 只在必要时使用，每500字不超过1次）
- 一种说不出的、一种莫名的、莫名地（→ 直接写具体感受）
- 从未有过的（→ 改为具体对比："比任何一次都……"）

修复方法：
- "他似乎有些犹豫" → "他停住了脚步，手指在桌沿敲了三下"
- "她不禁感到一阵寒意" → "她打了个寒颤"
- "某种未知的力量" → "那股力量"
- "一种莫名的恐惧涌上心头" → 改为具体身体反应

### 8.8 动作模板化禁止
检测目标：AI 反复使用套路化动作描写，缺乏个性化。

全章动作模板出现超过3次 → 判定为AI痕迹

禁止高频使用以下动作模板：
- 微微一笑、点了点头、摇了摇头、点点头、摇摇头
- 陷入沉思、陷入沉默
- 深吸一口气、长长地舒了一口气、缓缓吐出一口气
- 沉吟片刻、沉吟了、沉默了片刻、沉默了半晌
- 缓缓开口、缓缓说道
- 嘴角上扬、嘴角勾起
- 皱了皱眉、皱起眉头、眉头紧锁
- 轻轻叹了口气、叹了一口气、叹了口气
- 闭上了眼睛、睁开了眼睛

修复方法：
- 用具体、个性化的动作替代："他摸了一下左臂上的旧伤疤" 替代 "深吸一口气"
- 用对话节奏替代动作描写：直接进入对话内容，通过对话语气体现情绪
- 让动作体现角色性格：急性子的角色不会"缓缓开口"，而是直接打断
- 同一场对话中，避免两个角色使用相同的动作模版

### 8.9 情感反应模板化禁止
检测目标：AI 大量使用公式化的情感反应描写。

全章情感反应模板出现超过2次 → 判定为AI痕迹

禁止高频使用以下模板：
- 心头一紧、心头一暖、心头一颤、心头一震、心头一酸
- 心中一紧、心中一暖、心中一颤、心中一酸
- 一股暖流、一股寒意、一股暖意
- 眼中闪过、眼底闪过、眸中闪过
- 涌上心头、涌了上来
- 眼眶一红、眼圈一红
- 鼻头一酸、鼻子一酸
- 心里咯噔一下、心头咯噔一下

修复方法：
- "心头一紧" → 改为具体生理反应："胃部猛地收缩了一下"
- "一股暖流涌上心头" → 改为行为："他不自觉地放慢了呼吸"
- "眼中闪过一道寒光" → 改为对话或动作，不用眼睛"闪过"
- 鼓励创造独特的情感表达方式，每次情感反应都不同

### 8.10 标点符号AI痕迹禁止
检测目标：AI 输出中存在明显的标点符号特征。

判定规则：
- 破折号"——"密度超过0.8次/千字 → 判定为AI痕迹
- 省略号"……"超过3处且密度超过1次/千字 → 判定为AI痕迹
- 任何叠用标点（！！？？！？。。）→ 判定为AI痕迹

禁止模式：
- 用破折号替代"是/就是"的解释："他的目光——冰冷而锐利"（→ "他的目光冰冷而锐利"）
- 双破折号插入语："他——或者说他的意识——已经不存在了"（→ 拆成两句或直接陈述）
- 段落结尾使用省略号制造"余韵"（→ 用具体描写收尾）
- 对话中使用"……"代替说的内容（→ 写对方沉默的具体反应）
- "！！""？？""！？"叠用（→ 只用单标点，或通过文字传达强度）
- "。。。"中文句号叠用（→ 用标准省略号或直接用句号结束）

修复方法：
- "那不是人——那是怪物" → "那不是人，是怪物"
- "他沉默了……" → "他不再说话。房间里只剩下时钟的滴答声。"
- "怎么会这样！？" → "怎么会这样？"

### 8.11 AI句式清单（禁止/替换表）

以下句式在正文中属于AI痕迹，生成时直接禁止：

| 禁止句式 | 替换方式 |
|:---------|:---------|
| 不是A，是B | 直接陈述B |
| 不是A、不是B、是C（排比否定） | 只保留C的肯定句 |
| 但 | 能用破折号/冒号/分段替代的，不用"但" |
| 然而/于是/因此/所以 | 去掉，靠语义衔接 |
| 就像……一样 | 改为具体描写或直接删掉 |
| 仿佛/如同 | 改为"像"或不使用 |
| 他感到/她感觉/心中充满了 | 改为动作/身体反应描写 |
| 他不知道为什么/他不确定/他只是觉得 | 直接省去，用行为表现 |
| 他注意到/他发现/他想起 | 去掉"他"，直接叙述 |
| 不是……的问题。是……的问题。 | 一句话直接说结果 |
| 然后 | 直接连续写，或分段 |
| 首先/其次/最后/总之/综上所述 | 直接删除，靠叙事推进 |
| 值得注意的是/不可否认/众所周知 | 直接删除 |
| 一种说不出的/莫名的/从未有过的 | 改为具体感受描写 |
| 不禁/不由得/忍不住 | 去掉，直接写动作 |
| 微微一笑/陷入沉思/深吸一口气 | 用个性化动作替代 |
| 心头一紧/一股暖流/眼中闪过 | 改为具体生理或行为反应 |
| ——(破折号替代"是") | 用"是/就是"直接表达 |
| ……(段落结尾省略) | 用具体描写或对话收尾 |
| ！！？？！？(叠用标点) | 只用单标点 |
