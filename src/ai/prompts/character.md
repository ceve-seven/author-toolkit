# 人物四层档案规则集

## 1. 人物档案四层结构

每个角色必须构建完整的四层档案：

### 第一层：身份层（外部特征）
| 字段 | 要求 |
|------|------|
| 姓名 | 有寓意或与角色特征相关 |
| 年龄 | 具体数值，影响行为方式和世界观 |
| 职业 | 影响技能、知识边界和社交圈 |
| 背景 | 包含至少1个"形成性事件"（塑造了今日性格的事件） |

### 第二层：心理层（内在驱动力）
| 字段 | 定义 | 要求 |
|------|------|------|
| 动机 | 角色最想要的是什么 | 不能是抽象概念（"追求正义"→"找到杀害妹妹的凶手"） |
| 恐惧 | 角色最害怕的是什么 | 必须与动机形成对立张力 |
| 欲望 | 角色表面追求/声称想要什么 | 可以与真实动机不一致（自我欺骗） |
| 缺陷 | 性格中的致命弱点 | 必须在情节中导致至少1次重大失败 |

### 第三层：能力层（行动边界）
| 字段 | 要求 |
|------|------|
| 技能 | 具体技能列表，标注熟练度（初学/精通/大师） |
| 知识边界 | 明确标注角色"不知道什么"（比标注"知道什么"更重要） |

### 第四层：特殊层（叙事潜力）
| 字段 | 定义 | 要求 |
|------|------|------|
| 秘密 | 角色隐瞒的信息 | 必须有被揭晓的时刻安排 |
| 感知过滤器 | 角色观察世界时习惯性忽略什么 | 决定视角叙事的信息选择性 |

## 2. 感知过滤器设计

每个角色的感知过滤器决定了TA能看到什么、忽略什么：

- **范例（齐夏）**：习惯性观察人的微表情和语言矛盾，忽略环境物理细节
- **范例（乔家劲）**：关注威胁源的方位和逃离路线，忽略人际关系细节
- **要求**：感知过滤器必须与角色的职业/背景/性格一致
- **作用**：同一事件通过不同角色POV呈现时，信息有差异化

## 3. 角色一致性约束

角色行为必须遵循以下三层验证：
1. **动机链验证**：角色做某事的理由必须在之前3章内有铺垫
2. **知识边界验证**：角色不能做出基于"他不知道的信息"的决策
3. **性格一致性验证**：角色的选择是否符合已建立的人格特质

性格一致性允许的例外：
- 在极端压力下（生死关头/情绪崩溃）可出现"违背性格"的行为
- 但必须在事后有合理的解释或角色自我质疑

## 4. 角色关系化学

核心角色之间必须存在以下至少2种关系张力：
- **目标冲突**：甲方要的恰好是乙方失去的
- **价值观冲突**：两人认为"正确的事"完全不同
- **信息不对称**：甲方知道乙方不知道的关键信息
- **情感债务**：甲方欠乙方人情/乙方伤害过甲方

## 5. 禁止规则

- 禁止完美角色（无缺陷、无恐惧、无秘密）
- 禁止角色背景是毫无伏笔的"普通上班族突然觉醒"
- 禁止角色知识边界无限（什么都知道/关键时刻总能想起相关知识）
- 禁止角色的感知过滤器与普通人无异（无特色视角 = 无存在感角色）
