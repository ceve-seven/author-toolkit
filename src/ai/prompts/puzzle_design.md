# 推理/谜题设计规则集

## 1. 谜题类型分类

AI生成的谜题必须明确归属于以下类型之一：
- **信息差型**：不同角色掌握不同信息，通过信息交换/冲突推进
- **逻辑推理型**：通过线索链推导出唯一合理的结论
- **规则破解型**：在给定的规则/限制中找到"规则的漏洞"
- **心理博弈型**：通过预测对手行为获胜

## 2. 线索前置规则

每条推理线索必须满足：
1. **显性线索**（读者能直接看到）：在谜题揭晓前的1-3章中出现
2. **隐形线索**（读者能回看发现）：在谜题揭晓前的3-8章中埋设
3. **关键线索禁止规则**：决定性线索距离解谜章节不得少于0.5章（避免"主角突然发现关键证据"的作弊式推理）

## 3. 反转设计规则

每个重大反转必须满足：
1. **意外性检验**：让不熟悉情节的人评判，确认"出乎意料"
2. **必然性检验**：反转后回看前文，线索必须清晰可见
3. **影响性检验**：反转必须改变角色的决策路径或读者对前文的理解
4. 同一作品中，重大反转（影响后续3章以上）的间隔不得少于15章

## 4. 推理过程可视化规则

当角色进行推理时，系统必须确保：
1. 推理分步展开，每步只推导一个结论
2. 排除法：展示被排除的错误假设
3. 证据来源清晰：每个证据标出来源（"X在第3章说过Y""第5章第7段出现过Z"）
4. 推理过程不长于1000字，避免"长篇独白式推理"

## 5. 读者预期管理规则

1. **虚假安全区**：在第2-3个小谜题时，给读者一种"我已经掌握规律了"的错觉
2. **规则突破**：在第4-5个谜题时，打破读者已经建立的"规则认知"
3. **惩罚性后果**：角色推理错误的代价必须可见且持续（不能只是"推理错了重来"）
