# 《十日终焉》全卷创作Prompt体系

> 本文件由专业编辑、作家兼提示词工程师联合撰写，目标是将《十日终焉》的创作技法
> 转化为可复用的AI写作Prompt。每一卷的Prompt包含：核心技法、写作规则、对话范例、节奏图表。

---

## 卷1·说谎者游戏（第1-10章）

### 核心技法：三重反转开篇 + 逻辑推理破局

#### 开篇钩子Prompt

```
你正在创作一部悬疑脑洞小说的开篇。
请严格按照以下规则执行：

【场景规则】
1. 开场必须在一个封闭空间内（无门/无窗/不可理解的空间）
2. 所有角色在此苏醒，无人记得如何到达
3. 必须有一个非人感的NPC（戴面具/非正常体型/散发异味）
4. NPC必须在第一章内展示不可抗的暴力（瞬杀一人）
5. 空间内必须有可推理的物理线索（墙面线条/时钟/特殊标记）

【悬念递进规则】
第1章目标：建立"被囚禁"的恐惧 + 展示NPC的不可抗暴力
第2章目标：公布游戏规则 + 引入身份抽卡机制 + 主角抽到劣势身份
第3章目标：完成第一轮故事讲述 + 展示主角开始推理的迹象

【线索前置规则】
- "有且仅有一个说谎者"这句规则，必须在第8章被颠覆为"全员说谎者"
- 颠覆的依据（空气消耗量计算）所需的全部线索必须在第1章就埋设
  - 墙面横竖交错的线条（提示尺寸）
  - 座钟（提示时间跨度）
  - 山羊头称"九位"（提示人数疑点）
  - NPC说"沉睡了十二小时"（提示时间起点）

【禁止规则】
- 禁止主角在开篇获得任何"金手指"或"系统提示"
- 禁止主角通过回忆杀获得解题灵感
- 禁止NPC透露任何世界观背景
- 禁止前三章出现超过100字的连续心理独白
```

#### 推理场景Prompt

```
角色即将进行核心推理。请按以下步骤构建推理段落：

【推理可视化的四层结构】
第1层：提出异常（"奇怪，这个房间太奇怪了"）
   - 主角感知到一个不合常理的细节
   - 描述这个细节的具体表现形式（如：线条、数字、气味）
   
第2层：关联线索（"没猜错的话……"）
   - 主角将多个孤立线索串联起来
   - 展示计算过程（空气消耗量=人数×时间×单人消耗）
   - 每一步计算都在读者可验证的范围内
   
第3层：排除干扰（"不对……"）
   - 主角推翻一个自然但错误的假设
   - 展示排除法的中间步骤（"如果羊头人是人……如果不算尸体……"）
   
第4层：惊人结论（"我们都死了"）
   - 结论必须让读者感到意外
   - 但回头看前文，所有证据已经存在

【推理文本的写作规则】
- 每段推理不超过200字
- 每段推理末尾必须有一个"停顿"（换行/省略号/角色沉默）
- 推理过程中穿插其他角色的反应（惊讶/怀疑/恐惧）
- 推理完成后必须有人验证/推翻/质疑
```

## 卷2·鱼叉与抉择（第11-16章）

### 核心技法：物理谜题 + 团队合作 + 牺牲/背叛的张力

#### 物理谜题设计Prompt

```
设计一个需要团队合作才能存活的物理谜题。规则如下：

【谜题设计规则】
1. 谜题的解决必须依赖"物理逻辑"而非"超自然能力"
   - 参照：桌面可转动→一百圈→春笋锥体阵型
2. 谜题的线索必须多模态呈现
   - 视觉线索：面具内壁的文字
   - 逻辑线索：需要将九人的家乡位置连成"右"字
   - 隐喻线索："春笋不怕雨打"
3. 谜题的解决需要全员参与，缺一不可
   - 每个人必须承担不可替代的角色
   - 一个人的失误会导致全员死亡
4. 谜题必须有"虚假解法"和"真实解法"
   - 虚假解法：用大桌板错落防守
   - 真实解法：丢掉大桌板、小桌板组成春笋锥体

【合作张力规则】
- 至少设计一个角色提出错误方案且有理有据（赵医生的方案）
- 至少设计一个角色必须做出牺牲（韩一墨被鱼叉贯穿）
- 至少设计一个角色出现动摇（甜甜松手导致危机）
- 主角必须在关键时刻给出正确方向，但理由只有他懂

【节奏控制规则】
- 关卡开始→全员恐慌→短暂冷静→尝试错误方案→主角给出正确方案→执行中受伤→几乎失败→成功存活
- 整个过程不能超过3章
- 必须在第2章中间设置"关键受伤事件"提升紧张感
- 必须在第3章结尾设置下一个谜题的线索（鱼叉上的文字）
```

#### 悬念转移Prompt

```
当一个谜题解决后，必须无缝转移到下一个谜题。规则如下：

【悬念转移规则】
1. 存活后的"喘息时间"不超过一章
2. 喘息时间内必须做到：
   a. 处理上一个谜题的遗留伤害（韩一墨的鱼叉处理）
   b. 揭示下一个谜题的线索（鱼叉上的"人羊"文字）
   c. 角色之间的关系有微小变化（乔家劲向齐夏示好被拒）
3. 下一章开始前必须有一个"不可逆的物理变化"
   （天花板出现孔洞/墙面出现新机关/尸体被回收）

【奖励/惩罚规则】
- 存活下来的奖励不是安全，而是"知道下一关怎么死"
- 鱼叉上的文字既是下一关的线索，也是"羊会说谎"的陷阱
- 角色开始意识到"游戏不止一个"
```

## 卷3·羊与狗（第17-27章）

### 核心技法：二元对立设定 + 谎言识别 + 伏笔回收

#### 二元命题Prompt

```
设计一个"二元对立"的核心设定，规则如下：

【设定规则】
- "羊"代表的含义：说谎、诡计、陷阱、表面友好实际致命
- "狗"代表的含义：忠诚、合作、诚实、表面凶恶实际有利

【在情节中的具体应用】
1. "人羊"的规则必须全部打上问号
   - "死亡再次天降"→其实是地板上升
   - "站墙边是安全的"→站中央才是安全的
2. 角色需要学会识别"羊"和"狗"的区别
   - 通过回顾已有经验（第一个游戏=羊=说谎）
   - 通过对比不同NPC的行为
   - 通过推理NPC名字/规则的矛盾之处

【伏笔回收规则】
- 第1章羊头人自杀时选择打心脏而非打头 → 第17章揭示是为了保护面具内的文字
- 第2章"有且只有一个说谎者" → 第8章被颠覆 → 第17章被重新解释（羊=说谎者）
- 每个新信息出现时，都必须让已有的3个以上信息获得新的含义
```

## 卷4·分道扬镳（第28-40章）

### 核心技法：角色冲突 + 价值观对立 + 阵营分化

#### 角色冲突设计Prompt

```
当团队面临生存压力时，设计合理的内部冲突。规则如下：

【冲突类型】至少包含以下2种：
1. 价值观冲突
   - 李尚武（警察身份）：要维护秩序、保护所有人
   - 齐夏（骗子身份）：只求自保、必要时放弃他人
   - 触发点：是否应该冒生命危险救受伤的队友
   
2. 策略冲突
   - 激进派：乔家劲主张主动出击
   - 保守派：赵医生主张谨慎防守
   - 触发点：面对新游戏时选择"冒险解谜"还是"龟缩自保"

3. 信任冲突
   - 有人怀疑齐夏在利用众人
   - 有人怀疑团队中存在内鬼
   - 触发点：连续出现"只有小部分人知道的秘密信息被泄露"

【冲突升级的节奏】
- 第1阶段：暗流（眼神/沉默/阴阳怪气的对话）
- 第2阶段：爆发（当面争吵/拍桌子/互揭老底）
- 第3阶段：裂痕（分小组/小团体/不听指挥）
- 第4阶段：分裂（分道扬镳/分头行动/赌气出走）

【冲突写作规则】
- 每个人物的立场必须与他的背景/身份一致
- 冲突升级必须由外部压力触发（新游戏/新人死亡/资源不足）
- 冲突结束后，人物关系不能恢复如初，必须有"伤疤"
```

## 卷5·天堂口（第41-55章）

### 核心技法：新地图/新势力引入 + 世界观扩展

#### 新地图引入Prompt

```
当角色离开初始场景进入更大世界时，规则如下：

【新地图设计规则】
1. 新地图必须是对旧地图的"降维打击"
   - 旧地图：一个封闭房间（几十平米）
   - 新地图：一个完整的小镇/城市（天堂口）
   
2. 新地图必须有新的NPC势力和新的规则
   - 已有势力：十二生肖NPC（人羊、人狗、人猴等）
   - 新势力：原住民（地鼠等长期居住者）
   - 新规则：答贡（挑战生肖可以获得奖励/扣分）
   
3. 原住民的存在揭示更深层次的世界观
   - 十二生肖不是管理者，只是更低一级的执行者
   - 有"更高层"的存在（创造神/女娲计划）
   - 角色们开始理解"终焉之地"的真正结构

【世界观扩展的节奏控制】
- 每章只揭露一个世界观层级
- 每个新信息必须推翻或补充上一个信息
- 让读者感觉"知道得越多，越发现自己一无所知"
```

## 卷6·生肖游戏（第56-70章）

### 核心技法：多样化游戏设计 + 难度梯度

#### 游戏设计Prompt

```
设计一个"生肖游戏"，规则如下：

【游戏设计模板】
1. 游戏名称：[生肖名] + [核心玩法]
   - 范例：人猴·答贡、人鸡·赛跑、人猪·运气游戏
   
2. 规则设计三原则：
   a. 规则必须"看起来简单，实际上复杂"
      - 表面规则：比谁答题正确
      - 隐藏规则：答题只是幌子，真正的游戏是心理博弈
   
   b. 规则必须有"突破口"
      - 利用规则本身的漏洞（"举办者也是参与者"）
      - 利用NPC的性格弱点（人猴自负、人狗忠诚）
      - 利用环境因素（时间、地点、其他参与者）
   
   c. 规则必须允许"非公平获胜"
      - 可以使用欺骗
      - 可以使用暴力（在一定限度内）
      - 可以利用规则空白

3. 生肖NPC的人格设定
   - 每个生肖对应一个生肖动物的人格特征
   - 但必须有一个"反向性格"隐藏（表面凶恶实际善良/表面友好实际恶毒）
   - NPC必须有弱点和执念（贪财/好色/追求公平/渴望自由）
   
4. 游戏的赌注必须递增
   - 早期游戏：答贡点数
   - 中期游戏：肢体完整性（断手/断脚）
   - 后期游戏：生命/记忆/身份
```

## 卷7·回响觉醒（第71-82章）

### 核心技法：超自然系统引入 + 从规则到超越规则

#### 超自然系统引入Prompt

```
当故事从"纯智力游戏"转向"超自然能力"时，规则如下：

【回响系统的设计哲学】
1. 回响不是"新能力"，而是"已有能力的觉醒"
   - 齐夏从"靠智商看穿谎言"→回响"欺骗"
   - 乔家劲从"靠武力硬干"→回响"招灾"
   - 每个人的回响对应其人格特质的极致化
   
2. 回响的触发条件必须与角色的心理状态挂钩
   - 在极度绝望/愤怒/渴望时才能触发
   - 这与角色的过往经历直接相关
   - 触发后角色会有短暂失控
   
3. 回响不是"免费的外挂"
   - 使用回响有代价（消耗生命力/记忆/他人好感）
   - 回响可以被克制（更强的对手/特定的规则环境）
   - 过度依赖回响会失去人性

【从智力博弈到能力博弈的过渡技巧】
1. 回响的引入必须有"渐进过程"
   - 第1阶段：暗示（角色做到"不可能的事"但不自知）
   - 第2阶段：模糊（角色怀疑自己有了特殊能力）
   - 第3阶段：确认（有人解释回响的机制）
   - 第4阶段：训练（控制/强化/应用）
   
2. 回响不能解决一切问题
   - 核心谜题依然需要智力解决
   - 回响只是增加了"解题的维度"
   - 最强的对手依然是"无法用回响战胜的人"
   
3. 回响系统的引入必须推翻之前的认知
   - "我们之前以为这是囚笼/游戏→实际上是造神计划"
   - "十二生肖不是管理者→他们是失败品/实验品"
   - "回响不是超能力→这是被创造的法则"
```

## 卷8·终焉之战（第83章+，1000-1358章）

### 核心技法：多线融合 + 终极反转 + 情感收束

#### 多线融合Prompt

```
当故事进入最终阶段时，规则如下：

【多线融合规则】
1. 将所有已铺设的伏笔进行集中回收
   - 角色背景线（每个人的生前故事）
   - 世界观线（终焉之地的真正目的）
   - 势力线（十二生肖/天堂口/地魁等）
   - 关系线（齐夏与林檎/乔家劲与李尚武等）
   
2. 每个角色在终局之战中承担不可替代的职责
   - 齐夏：智力担当，设计最终策略
   - 乔家劲：武力担当，正面突破
   - 林檎：精神担当，稳定团队
   - 李尚武：指挥担当，组织战斗
   
3. 终局之战必须有一个"终极反转"
   - 反转必须让读者重新理解整个故事
   - 反转必须在第1章就有预兆（第一次读不会注意到）
   - 反转不能是"机械降神"（突然出现的外力解决一切）

【情感收束规则】
1. 每个存活角色必须有完整的"结局画面"
2. 每个牺牲角色必须有意义的"告别场景"
3. 主线解决的余波必须体现在角色的日常互动中
4. 结尾必须有"新的开始"的暗示
```

## 附录：通用写作规则（所有卷通用）

### 对话写作规则

```
【每段对话的三功能原则】
每段对话必须至少满足以下2项：
1. 推动情节（揭露信息/改变关系/制造转折）
2. 塑造性格（语气、用词、停顿、打断方式体现角色差异）
3. 制造紧张（潜台词冲突/权力博弈/信息差）

【禁止】
- 对话成为纯粹的信息搬运工具
- 两个角色用相同的语气和句式说话
- 一段对话超过5轮仍无信息增量
```

### 节奏控制规则

```
每800字必须出现以下至少1项：
- 新信息揭露
- 情绪变化（紧张→松弛/恐惧→愤怒/悲伤→希望）
- 悬念强化（引入新问题/深化已有危机）
- 场景或视角切换

连续1000字无以上任一项 → 标记为节奏塌陷，需重写
```

### 句式多样性规则

```
每300字范围内：
- 同一种句式开头（"他""她""这"）不超过2次
- 至少包含1句短句(≤8字)和1句中长句(≥25字)
- 过渡词（然后、接着、于是、但是、然而）密度≤2次/500字
```

### 情感表现规则

```
【禁止直接告知情感】
禁止出现以下表达：
- "他感到恐惧" → 改为"他的手指微微颤抖，额角渗出汗珠"
- "她非常愤怒" → 改为"她将手中的笔狠狠戳在纸上，笔尖折断"
- "心中充满了悲伤" → 改为"他张了张口，什么也没说出来，沉默地低下了头"
```

### 章末钩子规则

```
【每章结尾必设钩子】
1. 问题钩子（提出悬而未决的问题）
2. 悬念钩子（展示即将到来的威胁）
3. 反转钩子（颠覆读者认知的信息）
4. 情感钩子（触发强烈共鸣的瞬间）

禁止连续2章以上无强钩子（评分<6）
禁止连续2章使用同类型钩子
```
