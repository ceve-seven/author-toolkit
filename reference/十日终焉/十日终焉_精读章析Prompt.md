> - 结构图谱（章内节奏/信息/情绪三维分布）

## 第一幕：囚笼 | 第1章「空屋」

### 核心技法：环境先声夺人 + 暴力立威 + 不可抗NPC

### 结构图谱
```
信息密度：★★★★★  情绪压抑度：★★★★★  悬念值：★★★★★
线索密度：★★★★☆  对话/叙事比：60:40   字数：约1500字
```

### 节拍分析

| 节拍 | 内容 | 技巧 | 字数 |
|:----:|------|------|:---:|
| 环境建立 | 钨丝灯、圆桌、座钟、十人沉睡、山羊头 | 静谧→诡异的对比 | ~150字 |
| 人物苏醒 | 众人疑惑、山羊头自我介绍 | 群体反应差异化 | ~200字 |
| 异常感知 | 齐夏发现"无门"+ "九位" vs 十人 | 主角第一个疑点 | ~300字 |
| 规则初现 | 非法拘禁质疑 (章晨泽) vs 盲点质疑 (赵医生) | 人物性格亮相 | ~250字 |
| 暴力立威 | 山羊头撞碎年轻人头颅 | 不可逆暴力展示 | ~300字 |
| 恐惧定格 | 齐夏脸上粘着温热的大脑碎片 | 第一人称感官描写 | ~100字 |

### Prompt输出

```
【第1章写作指令 - 封闭空间+暴力立威】

1. 环境描写规则：
   - 使用3个感官维度（视觉、听觉、嗅觉）建立氛围
   - 视觉：昏暗灯光、斑驳家具、诡异线条 → 制造不安
   - 听觉：座钟滴答声、遥远的钟声 → 制造时间压迫感
   - 嗅觉：膻腥味、腐烂气息 → 制造生理不适
   - 禁止形容词堆砌，每个环境描写必须服务于"为什么这里不对"

2. 群体苏醒描写规则：
   - 不能所有人同时尖叫/质问
   - 至少一个冷静角色（章晨泽/齐夏）和至少一个暴躁角色（乔家劲）
   - 冷静角色的疑问必须指向事实矛盾，暴躁角色的反应指向情绪
   - 主角的观察必须细致入微且不引人注目

3. 暴力立威规则：
   - 杀人的动作必须在10秒内完成
   - 杀人前后的氛围对比：热闹质问→死寂→有人尖叫
   - 杀人后果必须被感官体验（"温热黏腻的碎片粘到脸上"）
   - 作为第一章结尾，必须让读者产生"这真的是一部小说吗"的震惊感
```

## 第2章「说谎」

### 核心技法：规则类怪谈 + 身份抽卡 + 主角劣势

### 结构图谱
```
信息密度：★★★★★  情绪压抑度：★★★★☆  悬念值：★★★★★
线索密度：★★★★★  对话/叙事比：70:30   字数：约2000字
```

### Prompt输出

```
【第2章写作指令 - 规则公布+身份抽卡】

1. 游戏规则公布的节奏控制：
   - 不能一次性全部公布
   - 分3-4次公布，中间穿插角色的反应和质疑
   - 第一次公布：基本规则（讲故事→投票→选对存活）
   - 第二次公布：有且只有一个说谎者（核心设定）
   - 第三次公布：身份卡（颠覆性机制）
   - 每次公布之间至少有1个角色的反应来"消化"信息

2. 身份抽卡的"作弊感"设计：
   - 主角是"说谎者"这个消息必须在第2章内部公开给读者，但不让其他角色知道
   - 抽卡过程必须是"第一人称受限视角"（读者知道主角抽到了什么，但不知道其他人）
   - 主角的心理活动：接受/计划/冷静（"死的是他们了"）
   - 主角的心理必须是灰色地带（不是圣母也不是极端利己）

3. 角色亮相的经济化手法：
   - 每个角色在第2章只需要出现2-3个特征
   - 甜甜：底层活泼/说话随意/肢体语言丰富/易被操控
   - 乔家劲：暴躁/粤语/重义气/直来直去
   - 章晨泽：冷静/法律思维/观察力强/略带傲慢
   - 李尚武：有组织能力/正义感强/略固执
   - 特征之间必须有"两两互动"（乔家劲 vs 李尚武的对话）
```

## 第8章「摊牌」

### 核心技法：逻辑推理高潮 + 证据链完整 + 身份公开

### 结构图谱
```
信息密度：★★★★★  情绪压抑度：★★★☆☆  悬念值：★★★☆☆
反转冲击度：★★★★★  对话/叙事比：50:50   字数：约2500字
```

### Prompt输出

```
【第8章写作指令 - 推理高潮+全员说谎者揭露】

1. 推理计算的呈现规则：
   - 必须分步展示计算过程，每一步都被读者验证
   - 第一步：单人空气消耗量（0.007m³/min × 60min = 0.42m³/h）
   - 第二步：十人总消耗（0.42 × 10 = 4.2m³/h）
   - 第三步：时间（12h沉睡 + 1h游戏 = 13h）
   - 第四步：总消耗（4.2 × 13 = 54.6m³）
   - 第五步：房间容积（4m × 4m × 3m = 48m³）
   - 第六步：结论（54.6 > 48，空气不够 → 我们已死）
   - 呈现方式：对话/独白交替，避免连续的内心独白

2. "全员都是说谎者"反转的手法：
   - 循序渐进：先证明空气不足→暗示已死→再解释为什么大家在说谎
   - 每个角色被点出谎言时：用质疑句式（"甜甜，你真的被广告牌砸中了吗？"）
   - 每个角色被点名后：沉默/低头/眼神闪躲（用动作表现被戳中）
   - 核心证据：身份卡翻开→全员「说谎者」
   - 颠覆了第2章"有且只有一个说谎者"的规则
   
3. 齐夏第二章末的成长弧：
   - "本来我不想救你们的"→非英雄式坦白
   - "如果有人选错我也会死"→利己但诚实的动机
   - "有人在外面等我"→最后的温柔
   - 既不是纯粹善良，也不是彻底冷血 → 灰色人物
```

## 第13章「一场雨」

### 核心技法：物理谜题设计 + 春笋阵型灵感 + 团队生存

### 结构图谱
```
信息密度：★★★★☆  情绪紧张度：★★★★★  合作温度：★★★★★
创意指数：★★★★★  对话/叙事比：40:60   字数：约2000字
```

### Prompt输出

```
【第13章写作指令 - 物理谜题+破局思维】

1. 物理谜题的破局设计：
   - 表面解法（大桌板保护上方，小桌板错落保护四周）→看似合理实则危险
   - 核心线索："春笋不怕雨打"→用斜面卸力
   - 新解法（所有小桌板组成锥体，丢弃大桌板）→违反直觉但正确
   - 锥体的科学原理：鱼叉与桌面形成斜面接触，贯穿力大幅下降
   
2. "团队合作"的写作要点：
   - 必须有角色质疑主角的方案（赵医生："尖头朝上我无法挡腿"）
   - 必须有角色坚定不移地支持主角（乔家劲："我相信骗子说的"）
   - 必须有角色在关键时刻犯错（甜甜松手→韩一墨受伤）
   - 犯错后不能推卸责任，而是立即补救（乔家劲扶桌板）
   
3. 座钟分割桌面的视觉描写：
   - 描述不能超过5句话
   - 用比喻帮助理解（"如披萨一般分割"）
   - 关键细节：把手（让人理解桌板=盾牌）
```

## 第17章「羊和狗」

### 核心技法：二元对立设定决战 + 伏笔大回收

### 结构图谱
```
信息密度：★★★★★  反转冲击度：★★★★★  悬念值：★★★★☆
伏笔回收率：★★★★★  对话/叙事比：40:60
```

### Prompt输出

```
【第17章写作指令 - 二元设定+伏笔回收】

1. "羊和狗"的二元设定揭示：
   - 羊=说谎（放羊的孩子因为多次说谎而没有人相信他→死于狼口）
   - 狗=忠诚（狗是忠诚的象征→需要合作才有生路）
   - 这个设定必须让读者感觉"恍然大悟但之前完全没想到"
   
2. 成功回收的伏笔清单：
   - 第1章：山羊头称为"人羊" → 第17章揭示"羊=说谎"人羊的规则全靠不住
   - 第1章：羊头人打心脏不打断头 → 保护面具内的文字（第11章）
   - 第2章至第7章：全员说谎 → "羊"的游戏特征
   - 第11章面具文字："希望你们活下去" → "狗"的忠诚（这是真话）
   - 鱼叉上的文字："死亡再次天降" → "羊"的谎言（实际是地板上升）
   
3. 角色内部信任的分化写作：
   - 主角解释"羊和狗"的推理过程必须简洁有力
   - 有人立刻相信（林檎/乔家劲）、有人半信半疑（李尚武/赵医生）
   - 信任的分化将成为后续剧情的重要驱动力
```

## 第82章「回响」及后续觉醒章节

### 核心技法：超能力引入 + 从囚笼到造神计划

### Prompt输出

```
【回响系统引入指令 - 从智力到超自然转折】

1. 回响的定义：
   - 回响不是"额外获得的能力"，而是"潜能的觉醒"
   - 每个角色的回响与其人格特质强相关
   - 齐夏→"欺骗"（他毕生用欺骗谋生，如今拥有了欺骗世界的能力）
   - 乔家劲→"招灾"（他在街头打架招来各种麻烦，如今能主动引导灾难）
   - 回响的触发条件：在极度绝望/愤怒/渴望时
   
2. 从智力游戏到能力游戏的过渡规则：
   - 过渡期不能少于20章（保持悬疑感）
   - 回响的出现必须是"渐进式"的
   - 第一次出现：角色做到不可能的事，连自己都不理解
   - 第一次被他人发现：角色被质疑
   - 第一次被解释：有人科普世界规则（生肖/回响/造神计划）
   - 第一次主动使用：在小危机中尝试
   - 第一次成为破局关键：在生死攸关时使用
   
3. 超能力不离题的规则：
   - 回响不能解决所有问题
   - 即使有了回响，核心矛盾依然需要智慧和勇气
   - 回响的代价必须持续存在
```

## 第1358章「十日终焉」（终章）

### Prompt输出

```
【终章写作指令 - 多线收束+情感落点】

1. 结局类型：开放性收束而非皆大欢喜
   - 主要目标实现（逃离终焉之地/击败最终BOSS）
   - 但付出代价（有人牺牲/失去记忆/永远改变）
   - 留有回味（暗示更高层次的存在/未解的终极谜题）
   
2. 伏笔终回收规则：
   - 第1章"女娲造神"→终章揭示其真正含义
   - 齐夏"有人在外面等我"→终章揭示那个人是谁
   - 所有角色的原型/死因→终章提供完整解释
   
3. 情感落点：
   - 不要过度煽情，保持克制
   - 每个角色的结局用1-2句话概括，避免长篇告别
   - 用画面而非情感描述来冲击读者（"墙上的钟停了"）
   - 结尾最后一句必须让读者产生"再看一遍"的冲动
```
