## 四、优化详情

### 4.1 SchemaValidator（新增）

对 16 个数据步骤添加了输入结构验证，在模块执行前即拦截错误：

```python
# 执行流程（优化后）
1. 依赖验证
2. 输入结构验证 ← NEW
3. 约束验证      ← ENHANCED
4. 模块执行
5. 同步输出
6. 质量审查
7. 更新进度
```

验证规则示例：
- **步骤2**：`theme.surface_theme` ≥5字，`sub_themes` 非空
- **步骤3**：`acts` ≥2幕，`causal_chain` 存在，`rhythm_map` 非空
- **步骤14**：`volumes` 存在且 ≥2卷
- **步骤15**：每章 `scenes` 非空
- **步骤16**：每章字数 ≥100，`scenes` 非空

### 4.2 ConstraintsEngine（增强）

| 约束规则 | 作用步骤 | 触发条件 |
|----------|----------|----------|
| `no_integer_chapter_obsession` | 步骤14 | 分卷缺少 `boundary_gravity` |
| `manuscript_too_short` | 步骤16 | 章节字数 <200（warning）/ <100（error） |
| `scene_content_empty` | 步骤15 | 章节场景列表为空 |
| `scene_word_count_too_low` | 步骤15 | 场景字数 <50 |
| `manuscript_no_scenes` | 步骤16 | 正文缺少场景结构 |

### 4.3 质量规则（新增）

添加 `content_minimalism` 规则，应用于 `manuscript` 和 `detail_outline` 步骤，
检测空场景和字数严重不足章节。
